🧮 Calculator App

A simple and user-friendly Calculator Web Application built using HTML, CSS, and JavaScript.
It performs basic arithmetic operations with a clean and responsive interface.

✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔄 Clear / Reset
- 🔢 Decimal number support
- 📱 Simple and responsive design
- ⚡ Fast and easy to use

🛠️ Technologies Used

- 🌐 HTML
- 🎨 CSS
- ⚙️ JavaScript

📂 Project Structure

Calculator-App/
│
├── index.html
├── style.css
└── script.js

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in any web browser.
4. Start using the calculator! 🧮

🎯 Project Purpose

This project was created to practice HTML, CSS, and JavaScript and to understand basic JavaScript functionality and user interactions.
